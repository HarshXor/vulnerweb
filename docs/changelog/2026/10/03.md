## Changed — Worker now runs the vulnerable lab on Cloudflare

- Rewrote `src/worker.py` from the Flask hello-world into a self-contained
  Cloudflare Python Worker (`workers-py` SDK) port of the ShopNow vulnerable
  lab, so it actually runs on the Cloudflare Workers runtime (the previous
  Flask import crashed under `wrangler dev`: `No module named 'flask'`).
- Run via pywrangler: `uvx --from workers-py pywrangler dev|deploy`
  (requires `uv >= 0.12.3`; plain `npx wrangler dev` does not bundle the
  Pyodide packages). SQLite at `/tmp/shopnow.sqlite3` on MEMFS; OS command
  injection realised as code injection (`/admin/exec`) in the sandbox.
- Moved Flask-variant deps `requirements.txt` -> `requirements-fulllab.txt`
  (pywrangler aborts if a root `requirements.txt` exists); set
  `pyproject.toml` dependencies to `[]` + optional `fulllab` extra.
- Updated `tests/conftest.py` to stub `WorkerEntrypoint`/`Response` and
  rewrote `tests/test_worker.py` to cover the new Worker logic (seed/admin,
  JWT alg:none vs HS256 signature, prototype-pollution merge, SQLi query
  shape): 5 passed.
- Verified LIVE under `pywrangler dev`: admin:admin login, SQLi bypass, JWT
  alg:none, SSTI, IDOR api_key leak, /debug disclosure.



## Added — ShopNow vulnerable web-shop training lab

- Added `src/app.py`: a standalone intentionally vulnerable Flask web-shop
  ("ShopNow") for **authorized security training only** (local/isolated; not
  for public exposure). Independent of the existing Cloudflare Workers
  skeleton (`src/worker.py` unchanged).
- SQLite at `/tmp/shopnow.sqlite3` with idempotent schema + seed data
  (products for injection practice, reviews, coupons). Uploads at
  `/tmp/shopnow_uploads`. Hardcoded login `admin:admin` (cannot be changed);
  also seeds `carlos:montoya`. Shop/exploit surfaces are auth-gated.
- Implemented the full requested vulnerability set across a realistic
  production-style shop flow (no in-UI hints): SQLi, reflected/stored/DOM
  XSS, CSRF, clickjacking, permissive CORS, XXE, SSRF, OS command injection,
  SSTI, path traversal, broken access control/IDOR, weak authentication,
  WebSockets (no origin check), web cache poisoning & deception, insecure
  deserialization (pickle), information disclosure, business-logic flaws,
  Host header injection, unrestricted file upload, JWT (alg:none + weak
  secret), prototype-pollution-style merge gadget, race condition,
  NoSQL-style/API injection. HTTP request-smuggling target documented
  (requires a vulnerable front-end proxy).
- Added `requirements.txt` (flask, optional flask-sock) and `README_LAB.md`
  (run steps, credentials, isolation warning, full vulnerability map,
  starter exploits, Cloudflare Pages/Workers compatibility note).
- Verified: `python -m py_compile src/app.py` clean; smoke-tested the auth
  gate, `admin:admin` login, SQLi login bypass + UNION dump, JWT `alg:none`
  acceptance, and `/debug` information disclosure.
